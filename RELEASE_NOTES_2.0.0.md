## Breaking change

- Minimum Obsidian version is now 1.13.0. Users on older Obsidian versions should stay on AutoDater 1.2.0.

## Changes

- Migrated the settings tab to Obsidian's declarative settings API.
- AutoDater settings now appear in Obsidian's global settings search.

## Upgrade notes

- No settings migration is required. Existing `Created`, `Updated`, and date format values are preserved.
